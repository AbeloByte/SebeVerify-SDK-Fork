# Merchant Integration Guide: SebeVerify Web SDK

This guide explains how to integrate the SebeVerify verification flow into your existing website or application.

## 1. Installation

The SDK is available as a bundled JavaScript file that can be included via CDN or installed via NPM.

### CDN / HTML Script Tag
```html
<script src="https://cdn.sebeverify.com/v1/sebeverify-sdk.js"></script>
```

### NPM / Yarn
```bash
npm install @sebeverify/web-sdk
```

## 2. Basic Initialization

Initialize the SDK with your Client Token (generated via your backend) and configure the event listeners.

```javascript
import SebeVerify from '@sebeverify/web-sdk';

const verifier = SebeVerify.init({
  clientToken: 'ct_xyz789', // Generated by your backend
  redirectUrl: 'https://yourwebsite.com/dashboard', // Where to send user after success
});

// Configure event listeners
verifier.on('started', (sessionId) => {
  console.log('Verification started for session:', sessionId);
});

verifier.on('processing', () => {
  console.log('User has submitted images, AI analysis in progress...');
});

verifier.on('success', (result) => {
  console.log('Verification successful!', result);
  window.location.href = result.redirectUrl;
});

verifier.on('error', (error) => {
  console.error('Verification failed:', error.message);
});
```

## 3. Launching the Flow

### Method A: Start Now (Recommended for Mobile)
Trigger the verification flow immediately. On mobile, this redirects the user to the SebeVerify web app. On desktop, it opens a modal with a crossover QR code.

```javascript
document.getElementById('verify-button').addEventListener('click', () => {
  verifier.start();
});
```

### Method B: QR Code Embed (Custom Desktop UI)
If you want to display the QR code directly on your own page instead of in a modal:

```javascript
verifier.renderQRCode(document.getElementById('qr-container'));
```

## 4. Branding & Customization

You can customize the appearance of the SDK via the initialization options:

```javascript
SebeVerify.init({
  clientToken: 'ct_xyz789',
  theme: {
    primaryColor: '#6366f1',
    borderRadius: '12px',
    fontFamily: 'Inter, sans-serif'
  },
  language: 'en'
});
```

## 5. Security Best Practices

1. **Never hardcode Secret API Keys** in your frontend.
2. **Always use HTTPS** on your integration domain.
3. **Handle all events**: Ensure your UI provides feedback if the user experiences an error or if processing takes longer than expected.
4. **Backend Verification**: Do not rely solely on the `on('success')` event to unlock sensitive features. Always verify the verification status via your backend using **Webhooks**.
